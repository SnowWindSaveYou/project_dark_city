# 地点牌图片生成风格指南

## 确定风格：物语系列 / 新房昭之 × SHAFT

### 核心 Prompt 结构

```
Monogatari series anime background art, SHAFT studio style, daytime, no people.
[地点]: [核心视觉锚点描述], [氛围细节], flat color planes, precise shadow geometry, [饱和度/对比描述], eerie stillness, graphic design sensibility
```

---

### 关键词清单

**风格锚定（必须）**
- `Monogatari series anime background art`
- `SHAFT studio style`
- `graphic design sensibility`

**画面基础（必须）**
- `daytime` — 保持白天（之后叠加夜间图做时间过渡）
- `no people` — 空无一人强化"不对劲"感

**画风要素（必须）**
- `flat color planes` — 区域内无纹理渐变
- `precise shadow geometry` — 阴影为硬边几何色块
- `hard-edged shadow blocks` — 同上，可替换使用

**氛围要素（按需选用）**
- `eerie stillness` — 诡异静止感
- `overwhelming silence` — 压迫性的寂静
- `the bench is too empty` / `one specific thing is wrong but hard to say what` — 暗示"不对劲"的写法
- `uncanny quality of ordinary space` — 日常场景的超自然感
- `oversaturated [color]` — 某个颜色刻意过饱和

**构图要素（按需选用）**
- `strong one-point perspective` — 强烈的一点透视
- `strong centered composition` — 中轴对称构图
- `[element] pressing in from both sides` — 两侧压迫感

---

### 地点核心锚点设计原则

**不要用入口/外观**，要用**进入后的体验感**作为构图核心。

| 地点 | 锚点元素 | 备注 |
|------|---------|------|
| 医院 | 红十字标志 + 空轮椅 + 冷白灯光 | 入口外观可以，因为红十字本身图形感强 |
| 公园 | 空长椅 + 树冠隧道 + 几何光斑 | 不要用铁门，要用内部体验 |
| 小巷 | 自动贩卖机 + 极度压缩的走廊 + 稀疏电线 | 一个"不该在这里"的发光物体 |
| 医院走廊 | 消失点走廊 + 冷白地砖 + 空推车 | 内部场景 |

**每个地点只突出一个主视觉锚点**，其他元素保持极简。

---

### 经验教训

- **不要垫图**：参考图会把画风拉回原始风格，约束力过强
- **不要改时间**：黄昏/夜间只是换了光照，不是画风变化
- **不要堆砌图形元素**：多个强图形元素会互相干扰，丢失新房的留白克制感
- **氛围靠"缺失"**：一把空椅子比复杂背景更有物语感

---

### 图片尺寸规格

- 比例：`2:3`
- 目标尺寸：`515x768`
