# 设计变更：事件内部决策系统

> **版本**: v0.1 草案
> **关联文档**: game_design.md §3.5, §11
> **变更动机**: 解决玩法深度薄与进程感弱的问题

---

## 一、问题诊断

### 当前设计的根本缺陷

现有事件系统是**单向的**：玩家移动到格子 → 翻牌 → 结果发生在玩家身上 → 玩家承受。

整个过程中玩家没有主动决策，只是结果的接收方。这导致：

- **玩法深度薄**：真正意义上"我权衡后做了一个选择"的时刻极少，核心决策只剩路径规划（去哪）
- **进程感弱**：第 1 天和第 10 天的决策结构完全一样，资源状态的变化没有改变玩家的决策空间

### 为什么路径规划不够

路径规划（如何用有限步数覆盖所有日程目标）是有价值的决策，但它发生在**翻牌之前**。翻牌这个动作本身——游戏中最高频的操作——没有决策内容，是纯粹的随机承受。

## 二、核心设计变更：事件内部决策

### 变更原则

翻开卡牌后，玩家面对一个情境，需要选择**如何应对**，而不是直接承受固定结果。

**关键设计约束**：决策选项的最优解必须依赖玩家当前的资源状态。不能出现"A 选项永远更好"的情况——如果有明显优势选项，决策就失去意义。

```
理想决策结构示例（遭遇怪物）：

  A. 逃跑    → 消耗步数，安全撤离
  B. 对抗    → 消耗理智（低于默认扣除），成功则获得奖励
  C. 用道具  → 消耗道具，最稳定的解决方式

资源状态决定最优解：
  - 步数充裕  → A 可接受
  - 理智充裕  → B 更划算
  - 有道具    → C 最稳
  - 三者皆匮乏 → 硬撑（接受最差结果）
```

这样，玩家需要实时读取自己的资源状态来判断，同一个事件在不同时期的最优解不同——这直接带来进程感的改善。

### 事件类型分类仍然有效

6 种事件类型（safe/monster/trap/reward/plot/clue）定义的是**情境的性质**，不是结果。加入决策后不改变这个分类的意义：

| 大类 | 类型 | 决策的作用 |
|------|------|-----------|
| 危险 | monster / trap | 决定以何种代价面对或规避危险 |
| 正向 | safe / reward | 决定获取什么、是否冒险争取更多 |
| 叙事 | plot / clue | 决定获取哪条信息、如何推进故事 |

## 三、各事件类型决策设计（草案）

> 具体数值待平衡，以下仅为结构示意。

### 3.1 Monster（怪物）

核心张力：安全代价 vs 战斗风险 vs 道具消耗

| 选项 | 消耗 | 结果 |
|------|------|------|
| 逃跑 | 步数 -2 | 安全撤离，无资源损失 |
| 对抗 | 理智 -1（减半） | 成功则获得金钱奖励；失败仍扣理智 -2 |
| 用道具 | 消耗一件道具 | 稳定解决，无任何资源损失 |
| 观察记录 * | 理智 -1 | 事件转化为 clue，获得线索与灵感 |

> *「观察记录」为特殊选项，仅在翻牌前已使用相机拍摄该格时出现（胶卷已消耗）。

### 3.2 Trap（陷阱）

核心张力：步数绕路 vs 灵感侦测 vs 硬闯

| 选项 | 消耗 | 结果 |
|------|------|------|
| 硬闯 | 理智 -1，健康 -1（标准） | 直接通过，正常触发陷阱效果 |
| 绕路 | 步数 -2 | 安全通过，无资源损失 |
| 侦测 | 灵感 -1 | 陷阱转化为 clue，获得线索 |

### 3.3 Safe（安全）

核心张力：保守恢复 vs 冒险搜查

| 选项 | 消耗 | 结果 |
|------|------|------|
| 休息 | 无 | 恢复理智 +1 或健康 +1（二选一） |
| 搜查 | 步数 -1 | 随机：发现物品 / 发现隐藏 clue / 什么都没有 |
| 拍照留念 | 胶卷 -1 | 金钱 +5（将安全格转化为 photo 格，有钱币收益） |

### 3.4 Reward（奖励）

核心张力：稳拿基础奖励 vs 冒险争取更多

| 选项 | 消耗 | 结果 |
|------|------|------|
| 直接拿 | 无 | 获得默认奖励（金钱 +15 或长期胶卷 +1） |
| 深挖 | 步数 -1 | 可能获得双倍奖励，也可能触发隐藏陷阱 |

### 3.5 Plot（剧情）

核心张力：被动观察 vs 主动参与推进

| 选项 | 消耗 | 结果 |
|------|------|------|
| 旁观 | 无 | 获得剧情信息，理智 -1（默认） |
| 记录 | 灵感 -1 | 获得更完整的剧情信息，推进白夜故事线 |
| 介入 | 健康 -1 | 直接推进剧情，可能解锁额外对话或碎片 |

### 3.6 Clue（线索）

核心张力：记录基础线索 vs 深挖风险

| 选项 | 消耗 | 结果 |
|------|------|------|
| 记录 | 无 | 获得线索，灵感 +1（默认） |
| 深挖 | 步数 -1，理智 -1 | 灵感 +2，并附加一条高价值传闻 |

## 四、跨类型转化

部分决策可将一个事件的类型转化为另一个类型。这不是每种事件都有，而是作为特定情境下的「第三条路」，制造惊喜感。

已确认的转化路径：

| 原类型 | 转化目标 | 触发条件 |
|--------|---------|---------|
| monster | clue | 翻牌前已使用相机拍摄（「观察记录」选项） |
| trap | clue | 选择「侦测」选项 |
| safe | photo | 选择「拍照留念」选项（消耗胶卷） |

## 五、与相机系统的关系

### 相机系统不变

相机维持原有设计：
- **拍摄危险格**：消耗胶卷，预先无害化（跳过事件，不进入决策流程）
- **拍摄安全格**：消耗胶卷，雷达功能（提示最近危险格位置）

### 两套系统的共存关系

相机和事件内决策解决的是**不同时机的问题**，而非竞争关系：

```
面对危险格时，玩家先做前置决策：
  有胶卷 → 要不要用相机预先无害化？
    ├─ 用相机：跳过事件，消耗胶卷
    └─ 不用：翻牌，进入事件内决策

不用相机的理由是真实存在的：
  - 胶卷稀缺，留给更重要的格子
  - 某些选项（如「观察记录」）反而带来更好的收益
```

胶卷的稀缺性（每日 3 个不保留）保证了玩家不会在每格危险格上都用相机。当胶卷不够时，事件内决策成为主要的应对手段。

### 「观察记录」选项的设计意图

当玩家翻牌前已使用相机拍摄该格时，怪物事件会额外出现「观察记录」选项。

这意味着：
- 相机不一定用于「无害化」，也可以用于「准备更好的应对」
- 玩家面临新的选择：消耗胶卷换取更多决策选项，还是直接无害化？

## 六、对两个核心问题的改善

### 玩法深度

翻牌这个最高频的操作，从「随机承受」变为「基于当前状态的权衡决策」。每次翻牌都要读取资源状态，每次资源紧张的时候决策都更有张力。

### 进程感

同一个事件在不同时期的最优解不同：
- **游戏早期**（资源充裕）：可以冒险选择高收益高风险选项
- **游戏中期**（资源均衡）：精打细算，每次选择都有权衡
- **游戏后期**（资源紧张）：被迫接受次优选项，在压力下做决策

这让玩家能感知到自己当前的状态在游戏进程中的位置，而不是每天重复相同的操作。

## 七、待讨论的问题

- [ ] 各选项的具体数值平衡（消耗多少 / 获得多少）
- [ ] 决策选项的数量（目前为 2-4 个，是否合适）
- [ ] 失败结果的设计（某些选项有概率触发「失败」状态吗？）
- [ ] 是否保留「无决策」的事件（某些 safe 格是否可以直接通过，不弹决策界面）
- [ ] UI 层面：决策弹窗如何与现有事件弹窗整合
