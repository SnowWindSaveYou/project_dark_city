> **最后更新**: 2026-05-12
>

---

## 画风规范（AI生成 Prompt 准则）

### 基础风格
- **画风**：日式视觉小说背景画风，平涂赛璐珞风格
- **禁止**：无文字、无人物、无边框
- **尺寸**：2:3 竖版，512×768px

### 地点牌（翻开前）
- **视角**：城市街道视角，建筑外观/街景
- **光线**：白天晴朗自然光，蓝天白云（统一白天）
- **识别度强化策略**：透窗可见内部特征元素（如图书馆透窗见书架），避免建筑外观雷同
  - 图书馆 → 落地玻璃橱窗透出整排书架+暖黄灯光
  - 医院 → 透窗见病床/走廊/红十字标志区域
  - 健身房 → 透窗见器械/哑铃架
  - 银行 → 玻璃门透出柜台窗口/保险箱区域
  - 学校 → 铁栅栏围墙、操场一角可见
  - 公司 → 玻璃幕墙办公楼，透窗见工位/显示器
  - 公园 → 无需透窗，绿植/铁门入口/长椅即可识别
  - 小巷 → 白天，两侧建筑夹道，远处出口透光
  - 车站 → 站牌/站台轮廓/月台
  - 墓地 → 铁栅栏大门、墓碑远景
  - 教堂 → 哥特尖顶/彩窗
  - 警察局 → 门口警车/警示灯

### 事件牌（翻开后）
- **视角**：室内场景或特写，与地点氛围匹配
- **光线**：根据事件调性决定（safe类暖色，monster类冷色/暗调）
- **参考**：禁书卡（铁链+发光古书）作为事件牌风格基准
