# 中段日常触发事件 — 剧情设计草稿

## 设计说明

本文档定义"每日中段"可触发的短对话事件，用于填充早晚剧情之间的空白。

**两个事件池：**
- **地点专属**：玩家完成当日任务（抵达目标地点）时触发，与当前章节叙事有呼应关系
- **通用兜底**：当日任务完成时触发，无地点限制，章节范围内随机抽取，每条带 onceFlag

**内容原则：**
- 每场 2-4 个交换，不推主线，只展示关系状态
- 白夜"在场"感优先，不用每次都说有信息量的话
- 苏柚不主动暴露情绪，但行动会说话

**触发逻辑（待实现）：**
```
玩家完成当日任务（抵达目标地点 X）
  → 优先查 hookId="daily_goal_X"，条件匹配则触发（地点专属）
  → 无匹配则查 hookId="daily_goal_any"，章节内随机抽（通用兜底）
  → 仍无则静默
```

> 触发时机是"完成当日任务"，不是"踩到任意同类地点"。
> 同一地点类型在本局游戏中可能出现多次，但剧情只在任务完成节点触发一次。

## 一、苏醒章节（第 1-3 天）

情感底色：警觉 → 勉强接受

---

### 地点专属

---

#### H-1 医院门口
`hookId: daily_goal_hospital` · `chapter: awakening` · `onceFlag: mid_hospital_aw`

```
旁白：路过医院门口，苏柚不由自主地放慢了脚步。

白夜：……进去过吗？
苏柚：刚出院。你知道的。
白夜：……对。知道。

旁白：它没再说话，悄悄飘到离医院大门远一点的位置，
      像是在回避什么。
```

> 白夜的反应是前世记忆的暗示，不点破。它"知道"但回避，给后续真相留空间。

---

#### H-2 公园 / 绿地
`hookId: daily_goal_park` · `chapter: awakening` · `onceFlag: mid_park_aw`

```
旁白：路边花坛旁蹲着一只橘猫，白夜比苏柚先蹲下去了。

白夜：（很小声）过来……过来……

旁白：橘猫抬起头，走了两步，直接从白夜身体里穿了过去。
旁白：白夜趴在地上，低头看了看自己的手。

苏柚：（憋着笑）忘了你没实体？
白夜：……忘了。

旁白：橘猫在远处回头看了一眼，白夜还趴在地上没动。
```

> 轻松小片段，让白夜显得不那么可怕。"忘了"两字暗示它在努力融入日常，笨拙但真实。

---

#### H-3 便利店
`hookId: daily_goal_convenience` · `chapter: awakening` · `onceFlag: mid_convenience_aw`

```
旁白：白夜在货架前停了很久，盯着一排泡面研究。

苏柚：想吃？
白夜：不吃。只是……棠不买这个。

旁白：沉默了一拍。

白夜：（转过去）……没什么。走吧。

苏柚：（拿了一包放进篮子）我买。

旁白：白夜没说话，飘在苏柚身后，保持了比平时多一点的距离。
```

> 第一次出现"棠"这个名字，用最轻的方式，白夜自己打住了。苏柚的反应（买下来）不是安慰，是某种无声的"我听见了"。

---

### 通用兜底

---

#### A-1 挡路
`hookId: daily_goal_any` · `chapter: awakening` · `onceFlag: mid_amb_aw_01`

```
旁白：前面有人低着头快步走来，苏柚没注意。
旁白：白夜不知道什么时候飘到了她前面。
旁白：那人绕开了。只是走路的惯性，还是别的什么，说不清楚。

苏柚：你在做什么？
白夜：走路。
苏柚：你不用走路。
白夜：……习惯了。
```

---

#### A-2 红绿灯
`hookId: daily_goal_any` · `chapter: awakening` · `onceFlag: mid_amb_aw_02`

```
旁白：等红灯的时候，苏柚正在给白夜解释为什么要等。

苏柚：……红的不能走，绿的可以走，黄的——

旁白：话说到一半，她停下来了。

苏柚：你在城里待了这么久，这些你应该都知道的。
白夜：知道。
苏柚：那我在说什么。
白夜：不知道。但是你在说。
```

---

#### A-3 被穿过
`hookId: daily_goal_any` · `chapter: awakening` · `onceFlag: mid_amb_aw_03`

```
旁白：迎面走来的人从白夜身体里穿了过去，白夜没动。
旁白：这已经是今天第三次了。

苏柚：……不难受吗？
白夜：习惯了。
苏柚：什么时候习惯的？
白夜：很久了。

旁白：苏柚没再问，但走路的时候，悄悄往白夜那一侧靠了一点。
```

---

#### A-4 借玻璃看
`hookId: daily_goal_any` · `chapter: awakening` · `onceFlag: mid_amb_aw_04`

```
旁白：苏柚往右边的橱窗里瞥了一眼，
      借着玻璃的倒影确认白夜还在。
旁白：白夜也正好在看她。
旁白：两个人同时把视线移开了。
```

> 短但有分量。行动比台词更诚实。

## 二、磨合章节（第 4-7 天）

情感底色：接受 → 依赖 → 保护与控制的边界开始模糊

---

### 地点专属

---

#### B-1 学校 / 操场
`hookId: daily_goal_school` · `chapter: bonding` · `onceFlag: mid_school_bo`

```
旁白：学校废弃操场的角落，白夜让苏柚沿墙走了一段路，然后说"再来一次"。

苏柚：这是你教我的第几个"走路方式"了？
白夜：暗面里的步法。迷路的时候有用。
苏柚：好。

旁白：她没有问为什么，也没有问棠是不是也这样学过。
旁白：然后意识到：什么时候开始不问了的？
```

---

#### B-2 公司楼附近
`hookId: daily_goal_company` · `chapter: bonding` · `onceFlag: mid_company_bo`

```
旁白：楼道里撞见同事小周，她把苏柚拉到一边。

小周：你最近整个人感觉不一样了。是在交往吗？
苏柚：住朋友。
小周：哪来的朋友，你不是说你——
苏柚：老朋友，很久的那种。

旁白：回家路上，苏柚把这段对话告诉了白夜。

白夜：……我算朋友吗？
苏柚：（停顿）算。
白夜：（很安静地）嗯。
```

---

#### B-3 小巷 / 胡同
`hookId: daily_goal_alley` · `chapter: bonding` · `onceFlag: mid_alley_bo`

```
旁白：白夜突然飘到苏柚前面，挡住了路。

白夜：从另一条路走。
苏柚：为什么？
白夜：不安全。

旁白：等了几秒，远处传来一阵嘈杂声，几个人走进了巷子里。
旁白：什么也没发生。

旁白：不知道该不该谢它。说了谢谢，好像在替它的判断背书——
      但不说，又说不出口。

苏柚：……走吧。
```

---

### 通用兜底

---

#### B-G-1 奶茶
`hookId: daily_goal_any` · `chapter: bonding` · `onceFlag: mid_amb_bo_01`

```
旁白：苏柚在便利店门口犹豫了一下，买了两杯奶茶。
旁白：走到路边才意识到白夜不能喝。

白夜：……给我拿着。
苏柚：你拿不住——

旁白：白夜的手指拢住了杯子的外壁，杯子托在了它的手心上。
      某种特殊的努力。

白夜：我可以。
苏柚：……行吧。

旁白：白夜一路端着那杯奶茶，没有喝，就是端着。
```

---

#### B-G-2 推销
`hookId: daily_goal_any` · `chapter: bonding` · `onceFlag: mid_amb_bo_02`

```
旁白：商场门口有人拦住苏柚，递来一张传单。

传单员：您好，我们这里——

旁白：那人的视线忽然移开了，走向了别处。
旁白：白夜飘在苏柚肩膀旁边，什么都没做，只是看着那个人。

苏柚：……你怎么做到的？
白夜：他不感兴趣了。
苏柚：那不是你让他的？
白夜：也许吧。
```

---

#### B-G-3 过马路
`hookId: daily_goal_any` · `chapter: bonding` · `onceFlag: mid_amb_bo_03`

```
旁白：走到路口，苏柚往左边看了一眼，然后往右边看了一眼。

苏柚：白夜？
白夜：（从右边飘过来）在。

旁白：苏柚发现自己最近过马路前会习惯性地确认白夜在哪一边。
旁白：不是为了找它，只是……习惯了。
```

---

#### B-G-4 帮挑
`hookId: daily_goal_any` · `chapter: bonding` · `onceFlag: mid_amb_bo_04`

```
旁白：苏柚在超市里挑了半天，拿起一包，又放下。

白夜：左边那个。
苏柚：你怎么知道我喜欢哪个？
白夜：你上次买的就是那个。
苏柚：……行吧。

旁白：拿了左边那个放进篮子，走了几步，觉得哪里不对劲，
      但想不出哪里不对劲。
```

---

#### B-G-5 排队说话
`hookId: daily_goal_any` · `chapter: bonding` · `onceFlag: mid_amb_bo_05`

```
旁白：排队的时候太无聊，苏柚低声跟白夜说了一件公司的事。
旁白：说完才发现，这是她今天说话最多的一段。

苏柚：你都听了吗？
白夜：听了。
苏柚：那你觉得——
白夜：你同事说错了，但你没说。
苏柚：……你真的在听。
白夜：一直在。
```

## 三、真相章节（第 8-11 天）

情感底色：疏离加深 → 行为侵蚀浮出水面 → 诅咒逼近

---

### 地点专属

---

#### T-1 图书馆
`hookId: daily_goal_library` · `chapter: truth` · `onceFlag: mid_library_tr`

```
旁白：图书馆三楼的角落，白夜在书架之间穿行，
      在某一格前停了下来。

白夜：……这里的书摆法变了。
苏柚：你来过？
白夜：很久以前。

旁白：白夜伸手，手指穿过书脊，
      像是在确认什么不再存在的触感。

白夜：……忘了。不重要了。
```

---

#### T-2 墓地 / 公墓
`hookId: daily_goal_cemetery` · `chapter: truth` · `onceFlag: mid_cemetery_tr`

```
旁白：墓地的角落有什么东西在看苏柚，她回头，什么都没有。

苏柚：……有东西。
白夜：没有。
苏柚：我感觉到了。
白夜：（停顿）……是暗面的余波。不是实体，进不来。

旁白：白夜飘到苏柚旁边，靠得比平时近。

白夜：我在。
```

---

#### T-3 车站
`hookId: daily_goal_station` · `chapter: truth` · `onceFlag: mid_station_tr`

```
旁白：车站的人群里，苏柚看见了一个红色电话亭。
旁白：白夜飘过去，在电话亭外停了一下，然后回来了。

苏柚：怎么了？
白夜：没什么。以前的东西。
苏柚：以前什么？
白夜：……说过的，忘了。走吧，这里人太多了。
```

> 可选：若玩家已触发 `plot_phone_call`（废弃电话事件），本条可替换为不同台词——
> 白夜望着电话亭不说话，苏柚叫它，它说"没什么，那个声音不会再打来了"。

---

### 通用兜底

---

#### T-G-1 握刀方式
`hookId: daily_goal_any` · `chapter: truth` · `onceFlag: mid_amb_tr_01`

```
旁白：路过五金店的橱窗，苏柚的倒影定格了一秒。
旁白：她握着包带的手势不对——那是白夜教她握刀的方式。

旁白：她松开，重新握，正常了。

苏柚：（低声）没事的。

旁白：白夜没听见，或者没在意，继续飘在她旁边。
```

---

#### T-G-2 白夜变沉默
`hookId: daily_goal_any` · `chapter: truth` · `onceFlag: mid_amb_tr_02`

```
旁白：出门走了很长一段路，白夜一直没说话。

苏柚：怎么了？
白夜：没事。
苏柚：以前你不说"没事"。
白夜：……以前说什么？
苏柚：就是说。

旁白：白夜没有接这句话。
旁白：苏柚也没再问。
```

---

#### T-G-3 魔王低语（第一次）
`hookId: daily_goal_any` · `chapter: truth` · `onceFlag: mid_amb_tr_03`

```
旁白：路过一段很安静的街区，脑子里冒出了一个不像自己的念头。
旁白：声音很轻，像是自己的内心独白——又不完全像。

苏柚：……

白夜：（察觉到什么）怎么了？
苏柚：没事，走神了。

旁白：白夜看了她一眼，没说话，
      但之后一直飘得离她近一点。
```

---

#### T-G-4 镜中倒影
`hookId: daily_goal_any` · `chapter: truth` · `onceFlag: mid_amb_tr_04`

```
旁白：过商场的时候，苏柚在落地镜里看到了自己的走路姿势。
旁白：背挺得很直，肩膀微微后收。
旁白：像一柄收在鞘中的刀。

旁白：她停下来，白夜也停下来了。

苏柚：……
白夜：怎么了？
苏柚：没事。

旁白：调整了一下姿势，继续走。
旁白：白夜跟上来，什么都没说。
```

## 五、可复用的幕间日常

以下场景来自主剧情大纲的"幕间·日常"部分，适合直接纳入通用兜底池，条件写严格一些。

---

#### 灵魂拷问
`hookId: daily_goal_any` · `chapter: truth` · `min_day: 7` · `onceFlag: mid_jiuhun`

```
苏柚：我和棠谁好看？
白夜：（沉默了整整一分钟）你好看……但她气质好。
苏柚：那我和她谁做饭好吃？
白夜：你做的好吃……但她切的菜整齐。
苏柚：你就是忘不了她。
白夜：我没有，我只是……记性太好了。
```

---

#### 临终关怀（误）
`hookId: daily_goal_any` · `chapter: truth` · `min_day: 9` · `onceFlag: mid_linzhong`

> 建议：进入暗面最终区域前的当日中段触发

```
白夜：（一本正经）不管你想起了什么，都不要恨我。
苏柚：（严肃地点头）好。
白夜：还有……如果我在暗面里突然变丑了，你也要假装没看见。
苏柚：……你就担心这个？
```

---

#### 行为侵蚀（发现）
`hookId: daily_goal_any` · `chapter: truth` · `min_day: 8` · `onceFlag: mid_erosion`

```
旁白：早上苏柚对着镜子刷牙，忽然发现自己的站姿变了。
旁白：脊背挺得很直，肩膀微微后收。
旁白：她盯着镜子里的自己，牙刷停在嘴边。

旁白：——像一柄收在鞘中的刀。

旁白：换了一个姿势，刷完，漱口，出门。
旁白：没有告诉白夜。
```

> 此条比 T-G-4（路边橱窗）更直接，建议 T-G-4 先触发，本条作为后续强化，
> 条件加 `flag: mid_amb_tr_04`（先触发过橱窗版本）。
