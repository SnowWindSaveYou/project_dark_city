# 新游戏概念设计文档
**工作标题**：梦魔心理医生（暂定）
**状态**：概念阶段，持续讨论中
**最后更新**：2026-05-17

---

## 一、核心定位

基于「暗面都市」的基础机制框架（5×5随机棋盘探索），进行差异化设计的新游戏。

**核心差异**：
- 暗面都市：目标已知（日程格子），规划路径到达
- 新游戏：目标未知（锚点），通过线索追踪定位，探索本身就是调查行为

---

## 二、主角设计

### 三重身份

| 层面 | 身份 | 面向对象 | 说明 |
|------|------|---------|------|
| 本质 | 梦魔 | 自己 | 能够进入他人内心世界的存在，有自己的隐秘目的 |
| 职业 | 心理医生 | 病人/外界 | 合法接触目标的工具身份，专业且可信 |
| 包装 | 魔法少女 | 病人（在迷宫内） | 对病人展示的形象，温暖、可信赖 |

### 性格特征

**双面性**是核心：
- 对外（病人面前）：温柔、专业、真诚关怀
- 私下独白：目的性强、自我中心、带有雌小鬼气质

两面都是真实的——她确实在帮助病人，同时确实有自己的目的。这不是伪装，是内部的道德张力。

### 视觉资源
- 有 chibi 形象（用于关卡外界面装饰）
- 有立绘（用于关键叙事节点的独白/对话）

## 三、叙事框架

### 世界观基础

某座小城市发生了一场重大灾难。表象是普通事故（煤气爆炸/地震等），实际是**一场神秘仪式引发的灾难——仪式失败或被人阻止，留下了封印**。

**信息分层**：

| 层级 | 人群 | 对事件的认知 |
|------|------|------------|
| 表面 | 大多数幸存者、外界公众 | 普通灾难，已翻篇 |
| 内层 | 外围目击者（普通病人） | 感知到某些「不对劲」，但无法解释，留下心理阴影 |
| 核心 | 核心经历者（最终病人） | 直接参与者，明确知道真正发生了什么 |
| 场外 | 主角位置 | 知道性质（某存在被封印），不知道具体：怎么封的？封在哪？由谁完成？ |

**灾难规模感**：小城市层面是重大事件，全球范围内几乎无影响——类似偶尔出现在新闻末尾的某地地震。封印事件因此具有隐蔽性，主角可以「外来者」身份介入而不引人注目。

**参考氛围**：Fate/Zero 冬木市大火——局部重大灾难，表面化处理，内部有复杂的多方知情层级。

### 主线目标

某个危险的存在（魔王/邪神级别）被封印在那场灾难中。

主角知道「有东西被封印了」，但**不知道封印的关键信息**（地点、方式、参与者、解封条件）。

她的实际目的是：从当年相关人士的记忆中拼出完整信息，最终获得解封能力。

**主角与被封印存在的关系**：刻意保持模糊——梦魔的身份本身足以合理化这种行为，不需要过度解释。

### 结局设计

获得解封信息后，**玩家可以选择是否实际解封**。多结局设计，具体结局待定。

## 四、关卡外结构

### 时间压力：固定天数

关卡外以**固定天数**（如7天）为硬限制——到期后主角被教会/猎魔人等势力发现，被迫离开。

- 每天可选一名病人进行就诊（进入一次迷宫）
- 天数到期不算游戏失败，但直接影响收集到的信息量和结局

### 整体流程

```
开局
  主角持有：那场事件的基本情报
  已知：有东西被封印
  未知：怎么封的 / 封在哪 / 谁参与了
    ↓
中期（外围目击者阶段）
  2~3个外围病人，平行关系，可自选顺序
  每次就诊成功：
    → 得到「事件碎片」（拼出事件轮廓）
    → 得到「跨病人线索」（在其他病人迷宫内解锁额外选项）
    ↓
关键节点
  碎片累积到阈值 → 定位出核心经历者的身份/位置
    ↓
终局（固定）
  进入核心经历者的迷宫
  暗面层深处 = 封印现场的记忆
  → 获得解封信息
    ↓
结局选择
  解封 / 不解封 / （可能的第三条路）
```

### 关卡外界面

**信息板**（日常状态）：
- 病人档案（已知信息、就诊次数、信任度）
- 碎片拼图（收集进度，逐渐显现事件全貌）
- 背包（持有的跨病人线索、购买的道具）

**立绘+独白**（关键节点触发）：
- 进入某病人迷宫前：主角对目标的判断和目的
- 就诊成功后：主角整理收获，可能流露私下想法（雌小鬼面）
- 定位到核心经历者时：叙事高潮，情绪明显变化

Chibi 用于信息板界面的常态装饰，立绘保留给有台词的叙事节点。

### 道具经济

- 就诊收取**诊断费**（病人付钱，主角借此合法接触目标）
- 用诊断费购买**主动道具**辅助调查
- 道具通过诊断费在关卡外购买，带入迷宫使用；迷宫内无商店格

**主动道具列表**：

同类道具分2~3档，价格和数值成比例，玩家按当前缺口和预算自由选择。

| 道具名 | 档位 | 效果 | 主题说明 |
|-------|------|------|---------|
| 探照镜 | — | 翻牌前查看格子内容（固定次数） | 提前侦察，降低不确定性 |
| 信物 | 小/中/大 | 本次就诊额外+2/4/6步数 | 带去礼物/信任凭证，病人更愿意开放内心 |
| 记忆锚 | 小/大 | 阻止锚点偏移1/3次 | 稳住病人核心记忆，防止其逃避 |
| 奶茶 | 小 | 恢复少量san | 主角的日常小确幸，最便宜 |
| 蛋糕 | 中 | 恢复中量san | 稍微犒劳自己，中等价位 |
| 鸡尾酒 | 大 | 恢复大量san | 真的需要放松一下了，最贵 |

san恢复类道具（奶茶/蛋糕/鸡尾酒）来自主角自身的嗜好，与病人无关——是她在高压工作间隙给自己的私下补给。独白层可借此体现性格：花了多少钱、值不值得、今天特别需要。

san恢复道具可在**关卡外随时使用**（出发前补满，不占槽位），也可以**带入迷宫内使用**（占道具槽，作为应急储备）。两个时机都可用，玩家按需取舍：san充裕时槽位留给探索道具，san紧张时带一件进去保底。

## 五、关卡内结构

### 核心数值

| 数值 | 含义 | 特性 |
|------|------|------|
| 步数（信任度） | 病人允许医生探索其内心的深度，每次就诊的行动上限 | 基础值随熟悉度增长；就诊过程中可动态增加 |
| san值 | 医生自身的精神损耗 | 跨局持久化；每天开局小幅回复，道具可额外补充；归零=游戏失败 |

**步数的两个层次**：

- **基础步数**（熟悉度）：对同一病人就诊的累计次数决定每次进入的基础步数上限。反复就诊 = 主角对这片心理地形越来越熟练，起点更高。
- **动态步数奖励**（帮助性决策）：就诊过程中，选择「对病人有利」的事件选项时，**立即获得额外步数**。一次帮助病人的决策 = 病人当下更加开放，给你更多探索空间。

> 信任度不是独立数值，直接体现为步数奖励。「帮助病人」和「获得更多探索空间」之间的因果关系即时可见。

### 单次就诊流程

```
携带：跨病人线索（背包内）+ 当次道具
  ↓
进入表层迷宫（5×5）
  格子状态跨次保留（上次翻开的格子本次依然翻开）
  翻格触发事件 → 卡牌选择（最优解依赖当前资源状态）
  遭遇危险 → 触发普通战斗
  步数耗尽 → 本次就诊结束，下次继续
    ↓
覆盖率达阈值 + 翻开「关键记忆格」
  ↓
暗面层入口开启
  ↓
进入暗面层（更深的新地图，约4×4）
  事件强度更高，san损耗更重
  有跨病人线索时 → 遭遇特定事件可解锁额外选项
  遭遇危险 → 触发普通战斗
    ↓
找到锚点 → Boss战（叙事节点）
  ↓
Boss战胜利 → 就诊成功 → 获得碎片
```

### 迷宫格子状态：跨次保留

多次就诊同一病人时，已翻开的格子维持翻开状态。

- 探索有积累，不需要重走已知区域
- 玩家可以跨次规划：这次重点探索左侧，下次补右侧
- 锚点只偏移到未翻开的格子——可以通过包围策略限制锚点行动范围

### 锚点机制

- 锚点代表病人内心压抑的关键记忆，位于**暗面层**
- 位置初始未知，通过翻开线索格逐步缩小范围
- 翻开「应激事件」格时，锚点偏移（类P5宝物逃跑）
- 到达锚点 = 触发Boss战

### 暗面层触发条件

**基础触发**（无额外线索时）：
1. 表层覆盖率达到阈值（如16/25格）
2. 「关键记忆格」随之出现在迷宫中
3. 翻开关键记忆格 → 暗面层入口开启

**跨病人线索的作用**：
不影响覆盖率，而是在迷宫内遭遇特定事件时提供**额外的可选方案**。玩家知识储备越丰富，处理具体情况的手段越多。

### 战斗系统

战斗定位：**遭遇危险时不得不面对的障碍 + 剧情Boss战**，不是核心玩法循环。

### 卡牌分化：三重身份对应三种战斗风格

借鉴学园偶像大师的「加算底数×乘算窗口」两层buff结构，映射到主角三重身份：

| 身份 | 战斗风格 | 机制说明 |
|------|---------|---------|
| **心理医生** | 分析型 | 叠加「分析值」（加算底数），强化后续出牌效果；分析值**不消耗**，持续累积到战斗结束 |
| **魔法少女** | 爆发型 | 直接造伤 / 开启乘算窗口（有持续回合数）；窗口内打高价值牌 = 爆发 |
| **梦魔** | 操控型 | 干扰敌方行动、翻转伤害、规避危险；独立机制，不参与加算/乘算 |

**基础连击逻辑**：
```
心理医生牌 → 叠分析值（加算底数上升，不消耗）
  ↓
魔法少女牌 → 触发乘算窗口（持续X回合）
  ↓
窗口内打出高价值攻击牌 → 爆发输出
  ↓
梦魔牌 → 处理特殊威胁（敌方行动危险时操控/规避）
```

**摸牌制**：每回合摸3张打1张，其余丢弃（不累积手牌）。
- 随机性保留，靠机制设计缓冲坏手气（连摸心理医生牌 = 分析值大涨，后续爆发更强）
- 敌人行动预告（类StS）→ 知道此回合敌人不攻击时可安心叠底数

**输出公式**：攻击牌伤害 = 基础伤害 + 分析值，乘算窗口激活时 × 2

**时间压力**：Boss蓄力行动（非步数消耗）——玩家需在Boss释放前打完，或用梦魔牌打断。

**步数威胁**：不由战斗回合消耗；仅特定敌人的特殊攻击会直接扣步数（作为一种威胁类型）。

普通战斗2~3回合（设计目标，非硬性限制），来不及完整构建combo，主要靠即时判断；Boss战回合更多，才有空间完整展开三段节奏。

**普通战斗**（快速障碍）：
- 战斗伤害先打临时HP小池子，溢出才扣san——好的发挥可以接近零san损耗
- 胜利：小量san损耗；逃跑：消耗额外步数；失败：大量san损耗

**Boss战**（剧情节点）：
- 每个病人的锚点对应一场Boss战，Boss行动模式与该病人的创伤主题挂钩
- 战斗过程本身是叙事的一部分——打过去的过程就是「直面那段记忆」
- 跨病人碎片和道具在此可发挥辅助作用

### 基础卡牌草案

**心理医生（叠分析值）**

| 卡名 | 效果 |
|------|------|
| 共情 | 分析值+2 |
| 观察 | 分析值+1，查看牌库最上面3张，选其中1张放到顶部（下回合必定摸到） |
| 沉默 | 分析值+5，本场战斗好调窗口持续时间上限-1回合 |

**魔法少女（输出/开窗口）**

| 卡名 | 效果 |
|------|------|
| 星光弹 | 造成3+分析值点伤害 |
| 好调 | 开启乘算窗口（持续2回合，期间伤害×2） |
| 净化 | 移除敌人当前正在蓄力的一个行动 |

**梦魔（干扰/规避）**

| 卡名 | 效果 |
|------|------|
| 混梦 | 敌人下回合跳过行动 |
| 梦境编织 | 将敌方下次攻击转为治疗 |
| 侵食 | 复制敌人一层buff给自己 |

### 主角成长

两个来源，两种性质：

| 类型 | 来源 | 用途 | 持久性 |
|------|------|------|------|
| **记忆卡** | 病人迷宫内拾取 | 加入牌库，战斗摸牌时可摸到 | 仅限该病人迷宫，跨次保留 |
| **主动道具** | 诊断费购买 | 迷宫探索使用（探测格子、加步数等） | 跨病人持久 |

无独立被动道具——原先设计的buff修饰效果直接写在记忆卡的卡面上，打出时触发。

**记忆卡设计**：

记忆卡带身份标签（心理医生/魔法少女/梦魔），算入连击逻辑，但**不对应任何特定基础卡**——是有自己效果组合的独立新卡，可同时携带小额基础效果+修饰效果。

通用记忆卡（9种，3-3-3）：

| 前缀 | 身份 | 效果 |
|------|------|------|
| 凝思· | 心理医生 | 分析值+3，若上回合打出过魔法少女牌则额外+2 |
| 共鸣· | 心理医生 | 分析值+2，好调窗口激活时此效果变为分析值+5 |
| 洞察· | 心理医生 | 分析值+1，查看敌人接下来2回合的行动预告 |
| 律动· | 魔法少女 | 造成2+分析值伤害，好调窗口持续+1回合 |
| 星弹· | 魔法少女 | 造成分析值×2点伤害（无基础值） |
| 绽放· | 魔法少女 | 造成2+分析值伤害，好调窗口激活时窗口乘算+1（×2变×3） |
| 混沌· | 梦魔 | 敌人下回合跳过行动，分析值+2，造成2点伤害 |
| 编织· | 梦魔 | 将敌方下次攻击转为治疗，好调窗口+1回合 |
| 执念· | 梦魔 | 分析值+8（可叠加），每回合结束未打出攻击牌则扣1san（不叠加） |

**记忆卡分类（降低设计成本）**：

| 类型 | 设计方式 | 数量 |
|------|---------|------|
| **通用记忆卡** | 效果+图标统一，仅描述文本按病人替换 | 多 |
| **专属记忆卡** | 独特效果+独特图标，仅重要事件奖励 | 每位病人1~2张 |

通用记忆卡示例：同一个「好调窗口+1回合」效果，在A病人迷宫叫「和妈妈一起看烟火」，在B病人迷宫叫「考试全对时的感觉」——玩家看到的是不同情感碎片，机制完全一致。

**表层与暗面层的记忆卡**：通用卡效果不区分层级，两层都可出现。叙事重量差异通过描述文本体现——表层事件自然对应日常/温和的描述，暗面事件对应压抑/核心情感的描述。专属卡才是该病人独有叙事重量的主要承载。

**数量估算**：全程（表层+暗面层）可获取记忆卡机会约7~9次，玩家实际拾取6~8张，牌库从9张涨至15~17张。通用记忆卡设计约**8~10种效果**，覆盖三轴+跨轴联动。

**外部成长**（跨病人永久）：

收集碎片累积「洞察点数」，在关卡外的成长树中主动解锁。成长树混合所有外部成长维度：

| 节点类型 | 示例 |
|---------|------|
| 新基础牌 | 三个身份各有1~2张可解锁的新基础牌 |
| 属性强化 | 起始步数+1、san上限+X |
| 携带能力 | 道具携带槽+1（默认1件，解锁后可带2件） |
| 道具解锁 | 某些道具需先在树里解锁才能购买 |

基础牌库（9张初始）属于玩家自身，换病人后不重置。成长树解锁的新牌永久加入牌库。

### 两类跨局信息资源

迷宫探索和就诊成功可以获得两种性质不同的信息资源：

| 资源 | 内容 | 积累方式 | 用途 |
|------|------|---------|------|
| **主线碎片** | 灾难事件本身的信息片段（「当天有人在仪式现场」「封印的方式」） | 定量积累，在关卡外信息板上拼图显现 | 达到阈值→定位核心经历者，推进主线 |
| **跨病人线索** | 病人之间人际连接的信息片段（「A提到的蓝雨衣」「B当天的工作地点」） | 进入背包，不消耗 | 带入其他迷宫，遇到相关场景自动解锁额外选项 |

碎片拼的是「发生了什么」，线索连的是「他们之间有什么关系」。两者都可从迷宫内事件获取，主线碎片也在Boss战胜利后必得一份。

### 跨病人线索

**线索的获取**：迷宫内特定事件触发，或就诊成功后从病人记忆碎片中提取出与其他人相关的信息片段，自动进入背包。

**线索的使用规则**：
- **自动生效**：进入迷宫时无需手动装备，持有即生效
- **不消耗**：触发后不会从背包消失，可重复在不同病人迷宫发挥作用
- **通用**：不绑定特定病人/特定事件，只要持有，在任意病人迷宫遭遇对应事件时都能解锁额外选项

**触发方式**：当迷宫内某格事件与线索内容有对应关系时，该事件自动追加一个「你想到了……」的额外选项——原有选项不变，多出一条你原本没有的处理路径。

**设计意图**：
- 避免「卡关」：玩家不会因为漏做某事而永久错过信息
- 降低设计负担：通用线索不需要精确配对「只能在A病人处使用」
- 强化探索感：跑完更多病人 = 手里的工具更多，进入同一片迷宫会遇到不同的可能性

**关于线索放大镜道具**：线索既不消耗也自动触发，「主动使用线索」的工具槽已无设计空间，**线索放大镜从道具列表移除**。

### 事件奖惩系统

**事件可给予的奖励**：

| 奖励类型 | 说明 |
|---------|------|
| 步数+ | 病人信任度提升，开放更多探索空间 |
| san小回复 | 某段温暖/平静的记忆给医生短暂喘息 |
| 记忆卡 | 从事件中提炼出的战斗能力碎片，加入牌库 |
| 主线碎片 | 事件本身含有与灾难相关的信息，推进主线拼图 |
| 跨病人线索 | 触发可带到其他迷宫的人际连接信息 |
| 轻量道具 | 迷宫内一次性辅助道具（见下） |

**事件可施加的惩罚**：

| 惩罚类型 | 说明 | 典型触发条件 |
|---------|------|------------|
| 步数- | 病人抵触，关闭一部分内心 | 干涉性/强行推进的选项 |
| san- | 直接精神损耗 | 沉重/扭曲的记忆，暗面层为主 |
| 战斗触发 | 记忆防御机制被激活 | 特定选项或特定格子类型 |
| 锚点偏移 | 病人应激，核心记忆逃跑 | 激烈干预/强行揭露的选项 |
| 道具强制消耗 | 某选项需消耗携带道具才能执行 | 作为选项代价，非被动惩罚 |

**轻量道具**（迷宫内事件奖励，一次性）：

非物品，是迷宫内特定记忆留下的「痕迹」，叙事上以「某段清晰/稳定/温暖的记忆」呈现：

| 轻量道具 | 效果 | 对应正式道具 |
|---------|------|------------|
| 碎片记忆 | 查看相邻1~2格内容（1次） | 探照镜 |
| 信任瞬间 | 立即+2步数（1次） | 信物·小 |
| 稳定锚点 | 阻止下次锚点偏移（1次） | 记忆锚·小 |
| 平静片刻 | 恢复少量san（1次） | 奶茶 |

轻量道具找到后进背包，玩家自行决定何时使用。

### 核心叙事张力

治疗目标 vs 调查目标存在微观冲突：

> 这段记忆是病人痛苦的根源，彻底处理对病人最好——但其中可能封存着指向下一个人的线索，消融后就找不到了。

玩家在每个迷宫内的决策不只是机制层面的资源取舍，也在推进或牺牲叙事信息。

### 病人迷宫的风格差异

共享同一场灾难背景，但每个病人的记忆经过主观变形：
- 外围目击者：迷宫风格因个人记忆各异（当天在哪里、情绪状态）
- 核心经历者：迷宫最接近灾难现场的「客观」状态，视觉冲击最强

## 七、视觉风格

### 整体基调：Muse Dash 风

- 明亮、高饱和度的色彩
- 活泼的 chibi 比例人物
- 干净的线条，高对比度背景
- 事件插图以夸张表情、轻松氛围呈现——包括负面事件也保持活泼感

**风格与主题的契合**：主角对病人展示「魔法少女」的可爱形象，游戏对玩家展示明亮欢快的画面——两层都是「可爱外壳包着不那么可爱的内核」，风格本身就是叙事的一部分。

### 表层 vs 暗面层的视觉区分：色调反转

| 层级 | 视觉处理 |
|------|---------|
| 表层迷宫 | 标准 Muse Dash 风：暖色调、高饱和、活泼 |
| 暗面层 | 相同线条和 chibi 风格，但色调全面反转——亮色变深沉、暖色变冷色 |

- 暗面层是表层记忆的「底片」，同一个地方，被压抑、被颠倒的那一面
- 过渡动画：画面像底片冲洗一样翻转
- 同一套资源不同滤镜，开发成本可控

### 主角双面性的视觉表达

- Chibi（信息板日常）：活泼可爱，默认状态
- 立绘（叙事节点）：有更多表情变化，独白时可切换为「私下」的态度脸，体现人格落差
