## 一、核心定位

基于「暗面都市」的基础机制框架（5×5随机棋盘探索），进行差异化设计的新游戏。

**核心差异**：
- 暗面都市：目标已知（日程格子），规划路径到达
- 新游戏：目标未知（锚点），通过线索追踪定位，探索本身就是调查行为

## 二、主角设计

### 三重身份

| 层面 | 身份 | 面向对象 | 说明 |
|------|------|---------|------|
| 本质 | 梦魔 | 自己 | 能够进入他人内心世界的存在，有自己的隐秘目的 |
| 职业 | 心理医生 | 病人/外界 | 合法接触目标的工具身份，专业且可信 |
| 包装 | 魔法少女 | 病人（在迷宫内） | 对病人展示的形象，温暖、可信赖 |

### 性格特征

**双面性**是核心：
- 对外（病人面前）：温柔、专业、真诚关怀
- 私下独白：目的性强、自我中心、带有雌小鬼气质

两面都是真实的——她确实在帮助病人，同时确实有自己的目的。这不是伪装，是内部的道德张力。

### 视觉资源
- 有 chibi 形象（用于关卡外界面装饰）
- 有立绘（用于关键叙事节点的独白/对话）

## 三、叙事框架

### 世界观基础

某座小城市发生了一场重大灾难（具体类型待定，表象为自然灾害或事故）。

**信息分层**：

| 层级 | 人群 | 对事件的认知 |
|------|------|------------|
| 表面 | 大多数幸存者、外界公众 | 普通灾难（煤气爆炸/地震等），已翻篇 |
| 内层 | 外围目击者（普通病人） | 感知到某些「不对劲」，但无法解释，留下心理阴影 |
| 核心 | 核心经历者（最终病人） | 直接参与者，明确知道真正发生了什么 |
| 场外 | 主角位置 | 知道性质（某存在被封印），不知道具体：怎么封的？封在哪？由谁完成？ |

**灾难规模感**：小城市层面是重大事件，全球范围内几乎无影响——类似偶尔出现在新闻末尾的某地地震。这保证了封印事件的隐蔽性，也让主角可以以「外来者」身份介入而不引人注目。

### 主线目标

某个危险的存在被封印在那场灾难中。

主角知道「有东西被封印了」，但**不知道封印的关键信息**（地点、方式、参与者、解封条件）。

她的实际目的是：从当年相关人士的记忆中拼出完整信息，最终获得解封能力。

**被封印的存在**：定性为魔王/邪神级别。主角（梦魔）与其的具体关系刻意保持模糊——梦魔的身份本身就足以合理化这种行为，不需要过度解释。

### 结局设计

获得解封信息后，**玩家可以选择是否实际解封**。多结局设计，具体结局待定。

## 四、关卡外结构

### 整体流程

```
开局
  主角持有：那场事件的基本情报
  已知：有东西被封印
  未知：怎么封的 / 封在哪 / 谁参与了
    ↓
中期（外围目击者阶段）
  2~3个外围病人，平行关系，可自选顺序
  每完成一个迷宫：
    → 得到「事件碎片」（拼出事件轮廓）
    → 得到「人物线索」（指向相关人物）
    ↓
关键节点
  碎片累积到阈值
  → 定位出核心经历者的身份/位置
    ↓
终局（固定）
  进入核心经历者的迷宫
  最深暗面层 = 封印现场的记忆
  → 获得解封信息
    ↓
结局选择
  解封 / 不解封 / （可能的第三条路）
```

### 界面设计思路

**平时**：信息板界面
- 档案（已知病人信息）
- 碎片拼图（收集进度，逐渐显现事件全貌）
- 人物关系图（可选）

**关键节点触发立绘+独白**：
- 进入某病人迷宫前：主角判断和目的
- 完成迷宫后：主角整理收获，可能流露私下想法
- 定位核心经历者时：叙事高潮，情绪明显变化

Chibi 用于信息板界面的常态装饰，立绘保留给有台词的叙事节点。

## 五、关卡内结构（继承自暗面都市）

### 机制映射

| 暗面都市元素 | 新游戏对应 | 含义变化 |
|------------|----------|---------|
| 5×5随机棋盘 | 病人的内心迷宫 | 每个人的内心世界 = 独特的随机迷宫 |
| 步数预算 | 排斥度（病人对被探索的抵抗） | 每局有限步数，象征病人心理防线 |
| 理智值(san) | 跨局持久化的医生损耗 | 反复潜入他人内心的代价，无法完全恢复 |
| 暗面世界 | 病人内心更深处（压抑记忆层） | 越深越接近核心创伤/真相 |
| 传闻机制 | 方向性线索 | 指向锚点（目标）的位置线索 |
| 日程格（已知目标） | 锚点（未知目标，可追踪） | 目标从已知变为未知但可追踪 |

### 锚点机制

- 迷宫内有一个核心目标（锚点），代表病人内心压抑的关键记忆
- 锚点位置初始未知，通过翻开线索格逐步缩小范围
- 锚点会移动：当玩家翻开「应激事件」格时，锚点偏移（类P5宝物逃跑）
- 锚点只偏移到未翻开的格子（已翻格形成包围可以限制锚点行动范围）

### 病人迷宫的风格差异

共享同一场灾难背景，但每个病人的记忆经过主观变形：
- 外围目击者：迷宫风格因个人记忆而各异（当天在哪里、情绪状态）
- 核心经历者：迷宫最接近灾难现场的「客观」状态，视觉冲击最强

### 核心叙事张力（关卡内）

治疗目标 vs 调查目标存在微观冲突：

> 这段记忆是病人痛苦的根源，彻底处理对病人最好——但其中可能封存着指向下一个人的线索，消融后就找不到了。

玩家在每个迷宫内的决策不只是机制层面的资源取舍，也在推进或牺牲叙事信息。
